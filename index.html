Windows, macOS и Linux изнутри:
C и Python, агент мониторинга и ИИ-агенты

Книга о том, что происходит внутри операционной системы, когда работает программа: процессы и потоки, память, файлы, автозагрузка, сеть, службы и устройства. Каждая тема разбирается в три шага: вызов системных функций на C, сверка результата со служебными программами системы и новая проверка в сквозном проекте. Курс идёт сразу для трёх систем — Windows, macOS и Linux: переключатель на страницах глав меняет функции, команды и программы.

Сквозной проект — агент-сторож компьютера. Ядро на C обращается к системе, мозг на Python принимает решения и связывает агент с сервисом n8n и моделями ИИ. Модели ИИ используются с первой пары. В редакторе модель генерирует и разбирает код по запросу. В сценарии n8n модель составляет для человека текст тревоги. Во второй половине курса модель вызывает функции агента, чтобы собрать подробности о тревоге, а ИИ-ассистенты подключаются к агенту по протоколу MCP. За 24 пары агент получает 13 проверок, которые после каждой пары подтверждает нарушитель в GitHub Actions на всех трёх системах.
